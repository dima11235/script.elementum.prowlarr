# Elementum Prowlarr

Отдельный провайдер Kodi Elementum для поиска через ваш Prowlarr.
Идентификатор: `script.elementum.prowlarr`.
Версии 0.4.x используют движок Jackett 3.1.0 с клиентом Prowlarr.
Каждый провайдер хранит настройки в своём профиле Kodi.

## Требования

- Kodi с Python 3: Kodi 19 или новее.
- Elementum 0.1.119 или новее.
- Ваш Prowlarr с включёнными torrent-индексаторами и действующим API-ключом.
- Сетевой доступ от устройства Kodi к Prowlarr.
- Kodi-модули `script.module.urllib3` и `script.module.kodi-six`
  (ставятся из репозитория Kodi автоматически).

Остальные зависимости Python (aiohttp, torf и другие) уже входят в пакет
в `resources/libs/`. Порт использует интерфейс Elementum 0.1.119 и API Prowlarr 2.7.0.5723.

## Установка

1. Откройте **Releases** этого репозитория.
2. Скачайте ZIP последнего выпуска (например, `script.elementum.prowlarr-0.4.2.zip`) из файлов выпуска.
   Архивы GitHub **Source code** не являются установочными пакетами Kodi.
3. В Kodi откройте **Дополнения → Установить из ZIP-файла** и выберите пакет.
4. Откройте настройки **Elementum Prowlarr** в разделе программных дополнений.
5. Введите адрес Prowlarr и его API-ключ из **Settings → General → Security**.
   Адрес может содержать URL Base. Пример: `https://prowlarr.example/prowlarr`.
6. Нажмите **Проверить подключение**.
7. Проверьте, что провайдер включён в разделе провайдеров Elementum.

Если установлены оба провайдера, Elementum может опрашивать оба.
При полном переходе отключите Jackett в настройках провайдеров Elementum.
Дополнение не отключает и не удаляет другие провайдеры автоматически.

API-ключ хранится средствами Kodi в настройках пользователя и маскируется
в поле ввода. Это не шифрование файла настроек. Ключ не встроен в ZIP,
не записывается дополнением в журнал и не публикуется в исходниках.

## Работа поиска

Клиент читает список индексаторов Prowlarr через `/api/v1/indexer`.
Он пропускает отключённые индексаторы, Usenet и индексаторы на паузе.
Он параллельно опрашивает доступные индексаторы через `/api/v1/indexer/{id}/newznab`.
Если индексатор возвращает HTTP 429, поиск продолжает обрабатывать ответы остальных.

Для фильмов и сериалов провайдер ищет доступные русское и английское названия.
Настройка «Prefer titles in Kodi language» задаёт, какое название добавить
первым. Свободный поиск использует введённый текст. Провайдер передаёт год и номера
сезона и серии отдельно, если индексатор поддерживает эти поля.
При включённом умном поиске сериалов Jackett ищет по названию и доступным
годам серии, сезона и сериала. Для отдельной серии он фильтрует совпадения
по сезону и номеру серии. Для точного маркера `S01E01` или `1x01` год в названии раздачи необязателен. IMDb-поиск выключен по умолчанию.

Фильтры Jackett учитывают разрешение, тип релиза, размер, ключевые слова
и наличие раздающих. Если после проверки ссылок осталось меньше трёх точных
раздач серии, провайдер добавляет раздачи того же сериала до трёх результатов
в пределах заданного лимита. Провайдер передаёт точные совпадения первыми. Elementum может изменить
порядок. Дополнительные раздачи помечены «Possible match» и могут содержать
другие серии или целый сезон.

Доступны сортировка по разрешению, числу раздающих,
размеру и сбалансированный режим (`раздающие × 3 × оценка разрешения`).
Провайдер раскрывает перенаправления, преобразует файлы `.torrent` в магниты
и удаляет дубли по хешу раздачи. Ключ добавляется к URL только для загрузки
через настроенный Prowlarr.

## Обновление и возврат

Установите новый ZIP из Releases поверх прежней версии с тем же id.
Версия 0.4.0 сохраняет адрес и ключ из 0.3.x.
После обновления откройте настройки и проверьте фильтры, сортировку и лимит.
Для этих параметров версия 0.4.0 использует поля и значения по умолчанию Jackett.
GitHub Releases сами по себе не дают автоматическое обновление через Kodi.
Отдельный Kodi-репозиторий обновлений в этот выпуск не входит.

Для возврата отключите **Elementum Prowlarr** и включите прежний провайдер.
При необходимости установите сохранённый ZIP предыдущей версии.
Перед любым обновлением сохраните его пакет и пользовательские настройки
без публикации API-ключа. Ручной патч Jackett этот проект не изменяет.

## Сборка и выпуск

Зависимости Python не устанавливаются. Из корня этого проекта:

```bash
python3 -m unittest discover -s tests -v
python3 build.py
```

Пакет и SHA-256 появятся в `dist/`. Сборка включает исходники, ресурсы и переносимые Python-зависимости с лицензиями.
В ZIP не входят Git, workflow, тесты, локальные настройки и временные файлы.
При одинаковых входах и версии zlib результат воспроизводим побайтно.

Для нового выпуска измените версию в `addon.xml` и `CHANGELOG.md`,
сохраните изменения, затем создайте и отправьте тег соответствующей версии
(например, `v0.4.2`):

```bash
git tag v0.4.2
git push origin main
git push origin v0.4.2
```

GitHub Actions проверит код, соберёт ZIP и создаст Release с ZIP и SHA-256.
Workflow не требует персонального токена: используется встроенный токен
GitHub с правом записи содержимого только у задания публикации.
