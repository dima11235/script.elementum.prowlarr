# Elementum Prowlarr

Отдельный провайдер Kodi Elementum для поиска через ваш Prowlarr.
Идентификатор: `script.elementum.prowlarr`.
Он не заменяет файлы `script.elementum.jackett` и хранит настройки отдельно.

## Требования

- Kodi с Python 3: Kodi 19 или новее.
- Elementum 0.1.119 или новее.
- Ваш Prowlarr с включёнными torrent-индексаторами и действующим API-ключом.
- Сетевой доступ от устройства Kodi к Prowlarr.

Контракт проверяется по Elementum 0.1.119 и Prowlarr 2.7.0.
Совместимость с другими выпусками требует проверки; автоматические тесты
воспроизводят API без доступа к чужим серверам.

## Установка

1. Откройте **Releases** этого репозитория.
2. Скачайте ZIP последнего выпуска (например, `script.elementum.prowlarr-0.2.0.zip`) из файлов выпуска.
   Архивы GitHub **Source code** не являются установочными пакетами Kodi.
3. В Kodi откройте **Дополнения → Установить из ZIP-файла** и выберите пакет.
4. Откройте настройки **Elementum Prowlarr** в разделе программных дополнений.
5. Введите адрес Prowlarr и его API-ключ из **Settings → General → Security**.
   Адрес может содержать URL Base. Пример: `https://prowlarr.example/prowlarr`.
6. Нажмите **Проверить подключение**.
7. Проверьте, что провайдер включён в разделе провайдеров Elementum.

Если установлены оба провайдера, Elementum может опрашивать оба.
При полном переходе отключите Jackett в настройках провайдеров Elementum.
Дополнение не отключает и не удаляет другие провайдеры автоматически.

API-ключ хранится средствами Kodi в настройках пользователя и маскируется
в поле ввода. Это не шифрование файла настроек. Ключ не встроен в ZIP,
не записывается дополнением в журнал и не публикуется в исходниках.

## Работа поиска

Клиент запрашивает `/api/v1/indexer` и выбирает включённые torrent-индексаторы
без активной паузы. Поиск идёт параллельно через `/api/v1/indexer/{id}/newznab`.
Индексаторы на паузе видны в окне статуса. Если доступных индексаторов нет,
Kodi показывает причину сразу.
Для фильмов и сериалов дополнение ищет по русскому и английскому названиям,
когда Elementum передаёт оба варианта. Свободный поиск использует введённый
текст. Каждый новый поиск запрашивает свежие результаты.
Индексаторы с поддержкой параметров `season` и `ep` получают номера отдельно.
Для остальных дополнение формирует запрос вида `Название S01E02`.
Дополнительный поиск всего сезона включается отдельной настройкой. Если подходящих раздач нет,
клиент пробует название с годом серии, сезона и сериала, затем само название.
Поиск по году и названию принимает результаты с явным совпадением сезона
или серии. Комплекты сезона для поиска серии зависят от той же настройки.
Фильтр распознаёт номера в форматах `S01E02`, `1x02` и `1 сезон, серии 1–4`.
При запасном поиске он также учитывает название сезона и сквозной номер серии
с указанным годом.

В этой версии поиск выполняется по названию, году и номеру сезона/серии.
Специальный поиск по IMDb/TVDB не включён: у активных torrent-индексаторов
Prowlarr такие параметры не заявлены, и запрос без текстового названия
возвращает нерелевантные результаты.

Результаты можно сортировать по разрешению, раздающим, размеру или
«сбалансированно» (`раздающие × 3 × разрешение`). Фильтры: тумблеры
разрешений (2160p…480p и неизвестное), типы релизов (Blu-ray/Remux,
Web-DL/WebRip, HDTV, DVD, TVRip/IPTV, скринер/CAM/TS — по умолчанию
выключен, неизвестный тип), ограничения размера отдельно для фильма,
сезона и серии, обязательные и исключаемые слова, минимум раздающих.
Дополнение раскрывает перенаправления на магниты. Ссылки на файлы
`.torrent` передаются Elementum для чтения полных метаданных.
Дубли удаляются по хешу раздачи, а при его отсутствии — по ссылке. Ключ
авторизации добавляется только к ссылкам download на вашем Prowlarr;
внешним трекерам он не передаётся. Не перенаправляйте журнал Elementum
или URL результатов в публичные отчёты: сам Elementum и другие дополнения
могут журналировать полученные ссылки.

## Обновление и возврат

Установите новый ZIP из Releases поверх прежней версии с тем же id.
Настройки сохраняются в пользовательском каталоге Kodi.
GitHub Releases сами по себе не дают автоматическое обновление через Kodi.
Отдельный Kodi-репозиторий обновлений в этот выпуск не входит.

Для возврата отключите **Elementum Prowlarr** и включите прежний провайдер.
При необходимости установите сохранённый ZIP предыдущей версии.
Перед любым обновлением сохраните его пакет и пользовательские настройки
без публикации API-ключа. Ручной патч Jackett этот проект не изменяет.

## Сборка и выпуск

Зависимости Python не устанавливаются. Из корня этого проекта:

```bash
python3 -m unittest discover -s tests -v
python3 build.py
```

Пакет и SHA-256 появятся в `dist/`. Сборка использует явный список файлов;
в ZIP не входят Git, workflow, тесты, локальные настройки и временные файлы.
При одинаковых входах и версии zlib результат воспроизводим побайтно.

Для нового выпуска измените версию в `addon.xml` и `CHANGELOG.md`,
сохраните изменения, затем создайте и отправьте тег соответствующей версии
(например, `v0.2.0`):

```bash
git tag v0.2.0
git push origin main
git push origin v0.2.0
```

GitHub Actions проверит код, соберёт ZIP и создаст Release с ZIP и SHA-256.
Workflow не требует персонального токена: используется встроенный токен
GitHub с правом записи содержимого только у задания публикации.

## Происхождение

Новая реализация клиента на стандартной библиотеке Python.
Используется публичный контракт `elementum.provider.register`.
Сторонние библиотеки и исходники Jackett в пакет не включены.
Это независимый проект, не официальный компонент Kodi, Elementum или Prowlarr.
