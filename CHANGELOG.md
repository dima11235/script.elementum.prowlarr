# Изменения

## 0.2.0

- Сортировка результатов: разрешение, раздающие, размер, сбалансированно (`раздающие×3×разрешение`).
- Фильтр разрешений: отдельные тумблеры 2160p/1440p/1080p/720p/480p и неизвестного разрешения.
- Фильтр типа релиза: Blu-ray/Remux, Web-DL/WebRip, HDTV, DVD, TVRip/IPTV, скринер/CAM/TS (по умолчанию выключен), неизвестный тип.
- Ограничения размера отдельно для фильма, сезона и серии, с порогом «неизвестный размер».
- Gate по capabilities индексатора: параметры `season`/`episode` уходят только индексаторам,
  заявившим их в `tvSearchParams`; остальным достаточно текстового запроса `Название S01Eyy`.
- Поиск сезона для серии включён по умолчанию.

## 0.1.0

- Отдельный провайдер `script.elementum.prowlarr` для Elementum.
- Поиск через Prowlarr API v1 по реальным включённым torrent-индексаторам.
- Фильмы, сезоны, серии, локализованные названия и дополнительный поиск сезона.
- Фильтры по раздающим, размеру и словам; сортировка и удаление дублей.
- Поддержка URL Base и авторизации ссылок загрузки Prowlarr.
- Стандартная библиотека Python; дополнительные Python-пакеты не требуются.
- Воспроизводимый установочный ZIP и GitHub Release по тегу версии.
