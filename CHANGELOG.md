# Изменения

## 0.4.3

- Для фильмов и сериалов проверяется название раздачи до фильтра по году, сезону и серии. Запасная выдача также требует совпадения названия.

## 0.4.2

- При менее чем трёх точных раздачах для серии умный фильтр дополняет выдачу раздачами того же сериала. Провайдер передаёт точные совпадения первыми и помечает дополнительные. Настроенные фильтры и лимит выдачи действуют на все результаты.

## 0.4.1

- Фильмы и сериалы ищутся по русскому и английскому названиям, если Elementum их передал.
- Точная серия с маркером `S01E01` или `1x01` проходит умный фильтр без года в названии раздачи.

## 0.4.0

- Дополнение целиком перенесено с проверенного `script.elementum.jackett` 3.1.0 (fugkco, WTFPL): движок поиска, фильтры (включая умный ТВ-фильтр по годам и сезонам), сортировка и разрешение ссылок — без новых алгоритмов.
- Клиент обращается к Prowlarr API v1 (`/api/v1/indexer`, `/api/v1/indexerstatus`, `/api/v1/indexer/{id}/newznab`) и обрабатывает паузы и HTTP 429.
- Адрес и ключ сохраняют идентификаторы из 0.3.x. Фильтры используют настройки Jackett с префиксом `elementum.prowlarr.`. Для отката используйте ZIP 0.3.14 и сохранённые настройки.
- Пакет включает переносимые Python-зависимости и их лицензии.
- Исправлены привязка настроек размера и условия фильтра ключевых слов в перенесённом коде.

## 0.3.14

- Проверка релевантности: значимые слова запроса (без союзов и года) обязаны быть в названии раздачи. Мусор индексатора с нерелевантной страницы («популярное», межстраничник Cloudflare) больше не попадает в результат.
- Проверка ссылок идёт до конца бюджета подключения порциями по 10 секунд. Медленные ссылки одного батча больше не отсекают релевантные раздачи остальных.

## 0.3.13

- Поиск учитывает срок ожидания Elementum. Аддон возвращает готовые раздачи, если индексатор или проверка ссылки ещё не закончили работу.
- Оба варианта названия получают время для поиска. Медленный ответ одного индексатора не задерживает выдачу после дедлайна.

## 0.3.12

- Исправлен счётчик завершённых запросов. Ошибка текста индикатора больше не прерывает поиск.

## 0.3.11

- Фильмы и сериалы ищутся по русскому и английскому названиям, если Elementum передал оба варианта. Сбой одного запроса сохраняет результаты остальных.
- Удалены кэш выдачи, порог запуска второго запроса и объединение раздач по имени и размеру.
- Проверка ссылок ограничена общим временем. Файлы `.torrent` передаются Elementum с исходными метаданными.
- Запасной поиск серий учитывает название сезона и сквозной номер серии.

## 0.3.10

- Пауза индексаторов видна весь поиск: имена и время снятия паузы — в заголовке окна статуса; если в паузе все индексаторы, окно держится на экране ~3 секунды с этим объяснением вместо мгновенного закрытия.

## 0.3.9

- Окно статуса показывает итог проверки ссылок: «Проверено ссылок: {прошло}/{найдено}».
- Если проверка не прошла ни одна ссылка (трекер в ограничении), найденные раздачи всё равно передаются в Elementum с исходными ссылками — вместо пустого результата.

## 0.3.8

- Проверка ссылок: лимит 10 секунд на одну ссылку — медленный трекер больше не отменяет результаты остальных; `.torrent`-ответы конвертируются в магниты (воспроизведение не зависит от трекера); одинаковые раздачи предпочитают магнит; пустая выдача не кэшируется.
- Окно статуса без сообщений об ошибках: счётчики запросов и проверки ссылок как в дополнении Jackett, ошибки только в журнал Kodi.

## 0.3.7

- Повторные поиски того же фильма в течение 2,5 минут возвращаются из кэша и не отправляют запросы трекерам: серии вызовов Elementum больше не приводят к ограничениям трекеров.
- Английское название запрашивается у индексатора только если по локализованному названию он вернул меньше 5 раздач: объём запросов ниже, покрытие обоих языков сохраняется.

## 0.3.6

- Окно статуса показывает индексаторы, поставленные трекером на паузу, с временем снятия паузы: RuTracker при ограничении запросов больше не исчезает молча.

## 0.3.5

- Одинаковые раздачи разных индексаторов объединяются в одну строку: в поле провайдера перечисляются все источники, раздающие и пиры берутся по максимуму — как в дополнении Jackett.

## 0.3.4

- Раздача, найденная по обоим названиям, показывается один раз: кандидаты сравниваются по индексатору, названию и размеру до раскрытия ссылок.

## 0.3.3

- Фильмы и сериалы ищутся и по локализованному, и по английскому названию: каждый индексатор получает оба запроса, результаты объединяются и дедуплицируются по хешу раздачи.

## 0.3.2

- Для фильмов и сериалов поиск использует локализованное название Kodi и не подменяет его общим запросом Elementum, как в дополнении Jackett: RuTracker находит русские названия.
- Во время поиска не показываются всплывающие уведомления: остаётся только фоновое окно статуса с индексаторами и количеством раздач; ошибки пишутся в журнал Kodi и в окно статуса.
- Проверка ссылок использует весь таймаут подключения вместо фиксированных 10 секунд — меньше отброшенных раздач с индексаторов-прокси (RuTracker, 1337x).

## 0.3.1

- Kodi показывает список проверяемых индексаторов, количество раздач по каждому ответившему индексатору и итоговое количество раздач.
- Отдельное сообщение показывает проверку ссылок на раздачи.

## 0.3.0

- Поиск вызывает Torznab отдельно для каждого индексатора, как установленный адаптер Jackett.
- Совместимые индексаторы получают отдельные параметры года, сезона и серии. Для остальных дополнение добавляет эти данные к тексту запроса.
- При сбое одного индексатора дополнение сохраняет результаты остальных.
- Дополнение раскрывает перенаправления Prowlarr на магнит-ссылки и объединяет дубли по конечному хешу. Ссылки на файлы `.torrent` сохраняются с исходными метаданными.

## 0.2.2

- Фильтр распознаёт форматы `1x02`, `S01E01E02` и `1 сезон, серии 1–4`.
- Поиск полного сезона исключает отдельные серии и неполные подборки, если в названии указаны их номера.

## 0.2.1

- Номер сезона и серии передаётся в текстовом запросе Prowlarr.
- При пустой выдаче поиск пробует годы серии, сезона и сериала, затем название.
- Из выдачи исключаются раздачи с несовпадающими номерами сезона и серии.
- Ошибка дополнительного запроса сохраняет уже найденные раздачи.
- Восстановлен выбор английского названия при отсутствии перевода на язык Kodi.
- Магниты с одинаковым хешем объединяются даже при разных параметрах ссылки.
- Если выключить все варианты фильтра, он исключит все результаты.

## 0.2.0

- Сортировка результатов: разрешение, раздающие, размер, сбалансированно (`раздающие×3×разрешение`).
- Фильтр разрешений: отдельные тумблеры 2160p/1440p/1080p/720p/480p и неизвестного разрешения.
- Фильтр типа релиза: Blu-ray/Remux, Web-DL/WebRip, HDTV, DVD, TVRip/IPTV, скринер/CAM/TS (по умолчанию выключен), неизвестный тип.
- Ограничения размера отдельно для фильма, сезона и серии, с порогом «неизвестный размер».
- Gate по capabilities индексатора: параметры `season`/`episode` уходят только индексаторам,
  заявившим их в `tvSearchParams`; остальным достаточно текстового запроса `Название S01Eyy`.
- Поиск сезона для серии включён по умолчанию.

## 0.1.0

- Отдельный провайдер `script.elementum.prowlarr` для Elementum.
- Поиск через Prowlarr API v1 по реальным включённым torrent-индексаторам.
- Фильмы, сезоны, серии, локализованные названия и дополнительный поиск сезона.
- Фильтры по раздающим, размеру и словам; сортировка и удаление дублей.
- Поддержка URL Base и авторизации ссылок загрузки Prowlarr.
- Стандартная библиотека Python; дополнительные Python-пакеты не требуются.
- Воспроизводимый установочный ZIP и GitHub Release по тегу версии.
